## Create a refund

`POST /v2/refunds` refunds all or part of a payment.

### Request

#### Query parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `expand` | array | no | Accepts `payment` to embed related payment details in the refund response. Set `expand=payment` in the query string. |

```bash
curl -X POST https://api.example.com/v2/refunds?expand=payment \
  -H "Authorization: Bearer $API_KEY" \
  -d '{"payment_id": "pay_123", "amount": 500}'
```

#### Request body

| Field | Type | Required | Description |
|---|---|---|---|
| `payment_id` | string | yes | The payment to refund. |
| `amount` | integer | yes | Amount in minor units. |
| `reason` | string | no | Why the refund is issued. One of `duplicate`, `fraudulent`, or `requested_by_customer`. |

```bash
curl -X POST https://api.example.com/v2/refunds \
  -H "Authorization: Bearer $API_KEY" \
  -d '{"payment_id": "pay_123", "amount": 500}'
```

### Response

Returns the refund with `status` set to `pending` and `created_at` set to when the refund was created (RFC 3339 in UTC with millisecond precision, e.g. 2026-10-04T09:30:00.000Z). When `expand` includes `payment`, the response embeds the `payment` object with its `id`, `amount`, and `currency` alongside the refund.
