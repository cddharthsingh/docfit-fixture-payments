## refund.created

Sent when a refund is created.

| Field | Type | Description |
|---|---|---|
| `id` | string | Refund id. |
| `payment_id` | string | The refunded payment. |
| `amount` | integer | Amount in minor units. |
| `currency` | string | Currency of the refund. |
| `status` | string | Refund status, `pending`. |
| `reason` | string | Why the refund is issued. One of `duplicate`, `fraudulent`, or `requested_by_customer`. |
| `created_at` | string | When the refund was created. RFC 3339 in UTC with millisecond precision, e.g. 2026-10-04T09:30:00.000Z. |

```json
{
  "type": "refund.created",
  "id": "ref_123",
  "payment_id": "pay_123",
  "amount": 500,
  "currency": "usd",
  "status": "pending",
  "reason": "requested_by_customer",
  "created_at": "2026-10-04T09:30:00.000Z"
}
```

## refund.succeeded

Sent when the money has reached the customer.

| Field | Type | Description |
|---|---|---|
| `id` | string | Refund id. |
| `payment_id` | string | The refunded payment. |
| `amount` | integer | Amount in minor units. |
| `currency` | string | Currency of the refund. |
| `status` | string | Refund status, `succeeded`. |
| `reason` | string | Why the refund is issued. One of `duplicate`, `fraudulent`, or `requested_by_customer`. |
| `created_at` | string | When the refund was created. RFC 3339 in UTC with millisecond precision, e.g. 2026-10-04T09:30:00.000Z. |
| `succeeded_at` | string | When the refund settled. |
| `arn` | string | Acquirer Reference Number. The card network's reference, shown on the customer's statement. Customers can give it to their bank to trace the refund. Absent for bank transfers. |

```json
{
  "type": "refund.succeeded",
  "id": "ref_123",
  "payment_id": "pay_123",
  "amount": 500,
  "currency": "usd",
  "status": "succeeded",
  "reason": "requested_by_customer",
  "created_at": "2026-10-04T09:30:00.000Z",
  "succeeded_at": "2026-10-04T09:31:00.000Z",
  "arn": "12345678901234567890123"
}
```

## refund.failed

Sent when the refund could not be paid out. The amount returns to the merchant balance.

| Field | Type | Description |
|---|---|---|
| `id` | string | Refund id. |
| `payment_id` | string | The refunded payment. |
| `amount` | integer | Amount in minor units. |
| `currency` | string | Currency of the refund. |
| `status` | string | Refund status, `failed`. |
| `reason` | string | Why the refund is issued. One of `duplicate`, `fraudulent`, or `requested_by_customer`. |
| `created_at` | string | When the refund was created. RFC 3339 in UTC with millisecond precision, e.g. 2026-10-04T09:30:00.000Z. |
| `failed_at` | string | When the refund failed. |
| `failure_code` | string | Reason for failure:<br />`expired_card`: Ask the customer for another card.<br />`account_closed`: Ask the customer for an alternative payment method.<br />`insufficient_balance`: Top up your merchant balance.<br />`declined`: Ask the customer to contact their card issuer. |
| `failure_message` | string | Human-readable explanation, safe to show to the merchant. |

```json
{
  "type": "refund.failed",
  "id": "ref_123",
  "payment_id": "pay_123",
  "amount": 500,
  "currency": "usd",
  "status": "failed",
  "reason": "requested_by_customer",
  "created_at": "2026-10-04T09:30:00.000Z",
  "failed_at": "2026-10-04T09:31:00.000Z",
  "failure_code": "declined",
  "failure_message": "The refund was declined by the card issuer."
}
```

## refund.updated

Sent when `metadata` or `reason` changes on an existing refund.

| Field | Type | Description |
|---|---|---|
| `id` | string | Refund id. |
| `payment_id` | string | The refunded payment. |
| `amount` | integer | Amount in minor units. |
| `currency` | string | Currency of the refund. |
| `status` | string | Refund status. One of `pending`, `succeeded`, `failed`, or `cancelled`. |
| `reason` | string | Why the refund is issued. One of `duplicate`, `fraudulent`, or `requested_by_customer`. |
| `created_at` | string | When the refund was created. RFC 3339 in UTC with millisecond precision, e.g. 2026-10-04T09:30:00.000Z. |
| `previous_attributes` | object | The changed fields with their values before the update. Contains pre-update values of `reason` or `metadata`. |

```json
{
  "type": "refund.updated",
  "id": "ref_123",
  "payment_id": "pay_123",
  "amount": 500,
  "currency": "usd",
  "status": "pending",
  "reason": "requested_by_customer",
  "created_at": "2026-10-04T09:30:00.000Z",
  "previous_attributes": {
    "reason": "duplicate"
  }
}
```
